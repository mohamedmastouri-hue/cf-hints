# CF Hints

A minimal Chrome extension that generates Socratic hints for Codeforces problems.

## Load in Chrome

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click **Load unpacked**.
4. Select this folder.

## API Key

Open the popup settings gear and save your Mistral API key. The key is stored locally in `chrome.storage.local`.

## Supported Pages

- `https://codeforces.com/problemset/problem/*`
- `https://codeforces.com/contest/*/problem/*`
